# Project rules

Before making any UI changes, always read DESIGN.md.

The project must use only semantic HTML5, CSS3 and Vanilla JavaScript.

Do not use:
- React
- Vue
- Angular
- Tailwind CSS
- Bootstrap
- jQuery
- npm UI libraries
- build tools

Use the current KazATU website and official KazATU assets as the source of truth
for brand colors, logo, content and university structure.

DESIGN.md provides layout, typography, spacing and component principles only.
Do not copy IBM brand colors, logos or visual identity.

All pages must be responsive, accessible and work without compilation.
