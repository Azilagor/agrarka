# Сайт КазАТУ им. С. Сейфуллина

Многостраничный сайт университета на чистом HTML5 / CSS3 / vanilla JavaScript.
Без фреймворков, без npm-зависимостей, без сборщиков — открывается как обычный
статический сайт.

## Запуск

Из корня проекта:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000/index.html` в браузере.

Любой другой статический HTTP-сервер тоже подойдёт (сайт не использует
серверную логику), но пути в проекте — относительные, поэтому открывать
файлы напрямую через `file://` не рекомендуется (некоторые браузеры
блокируют `fetch`/модульные скрипты на этой схеме; здесь `fetch` не
используется, но локальный сервер — самый надёжный вариант).

## Архитектура

- **Sidebar не дублируется в разметке.** Каждая страница содержит только
  пустой `<div id="sidebar-mount">`; `navigation.js` строит туда меню,
  поиск, языковой переключатель и ссылку на Platonus один раз, для всех
  страниц одинаково. Активный пункт меню подсвечивается по `data-page`
  на `<body>`.
- **Футер** аналогично собирается один раз в `main.js` в `#footer-mount`.
- **Мобильное меню** — тот же sidebar, превращается в выезжающую панель
  ниже 960px (закрывается по Escape, клику по оверлею, клику по ссылке;
  блокирует прокрутку страницы).
- **Данные — простые JS-массивы**, без бэкенда: `PLACEHOLDER_PROGRAMS` в
  `programs.js`, `INSTITUTES` в `institutes.js`, `NEWS_ITEMS` в `news.js`.
  Все фильтры (поиск, уровень, институт, язык, направление, категория,
  год) и пагинация работают полностью на клиенте.
- **Многоязычность**: `data-page="home"` и языковой переключатель KZ/RU/EN
  уже работают для служебных строк интерфейса (меню, поиск, кнопки) через
  `i18n.js` и атрибуты `data-i18n`. Основной контент страниц — на русском;
  переводы на KZ/EN как следующий шаг (см. TODO).

## Реальные данные и их источники

Цвета, логотип, структура меню и часть контента (адрес, телефоны, email,
новости, институты) взяты с официального сайта kazatu.edu.kz. Список
институтов подтверждён пользователем. Там, где точных официальных данных
не было (стоимость обучения, сроки приёма, руководство, лицензия и т.д.),
на странице стоит видимый бейдж `TODO:` вместо выдуманных цифр или имён —
ищите `badge--warning` в разметке.

## Проверено

- Валидность HTML (баланс тегов, отсутствие дублирующихся атрибутов) — все 15 страниц.
- Единственный `<h1>`, уникальные `<title>`/meta description — все страницы.
- `alt` у всех изображений, `loading="lazy"` везде, кроме hero-изображения.
- Все внутренние ссылки и якоря (включая генерируемые из JS) — без 404.
- Консоль браузера — без ошибок на всех 15 страницах (включая динамические
  `?id=`-варианты).
- Фильтры (программы, новости), пагинация, FAQ-аккордеон, валидация форм,
  sidebar и мобильное меню — проверены кликом через headless Chrome.
- Адаптивность на 360 / 768 / 1024 / 1440 px, включая таблицы (обёрнуты в
  `.table-wrap` с внутренней прокруткой — страница не скроллится по горизонтали).
- Неиспользуемый CSS удалён (`.hero__eyebrow`, `.person-card__*`, `.tab-panel`).
